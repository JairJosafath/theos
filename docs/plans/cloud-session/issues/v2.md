## Context

The engine's lines above each CEL rule are on by default (setting `inlineInfo`). GitLens lets a person turn each annotation off with one command, and so must cel-lens (`docs/style/vscode.md`, *The UX bar*: "Every kind of annotation can be turned off").

## Goal

A setting and a command turn the inline lines off and on at once, and the status bar menu shows and flips the state.

## Acceptance criteria

- [ ] The setting `cel-lens.inlineInfo` (boolean, default `true`, resource scope, in the README's settings table) is sent to the engine at start and on change; changing it updates open editors without a reload.
- [ ] `cel-lens: Toggle Inline Info` flips the setting at the scope that set it (user by default) and is in the palette in YAML.
- [ ] The status bar item's menu has an entry `Inline info: on` or `off`, with the same effect.
- [ ] The README describes the lines with a picture placeholder named for a person to take, and the CHANGELOG has the entry.
- [ ] Tests cover the setting reaching the engine and the toggle's scope, against `test/vscode.ts`.

## Out of scope

The type picker: the previous issue.

## Dependencies

The engine's inline info issue, released.
