## Context

Second step of `docs/plans/cel-lens-rule-hovers.md` (JairJosafath/cel-lens#4). The hover has its frame and **Uses:**. The request asks for "what it checks, in a plain sentence (for example 'every port is below 65536')", and the plan (decision 3) settles how: a translation of the parsed expression by a fixed table of shapes, never the rule's `message`, and nothing when the table does not cover the whole expression.

## Goal

The hover says what a check expression checks in a sentence that is right whenever it is shown, says what a value expression returns, and shows nothing it could get wrong.

## Acceptance criteria

- [ ] A new package `internal/meaning` imports cel-go's parser and nothing of Kubernetes, `internal/lsp` or `internal/assist`. It answers a sentence, or none, for an expression's text and its kind (a check, or a match condition).
- [ ] A table test holds each row of the plan's table to its exact sentence: `&&` and `||` chains, `!has(x) || B`, a ternary with boolean branches, the six comparisons, `size(x)` and `x.size()` compared, `has` and `!has`, `in` a list literal and `in` a value, `all`, `exists`, `exists_one`, `existsOne` and the two-variable forms, nested comprehensions, `startsWith`, `endsWith`, `contains` and `matches` with and without `!`, `isQuantity`, `isURL`, `isIP`, `isCIDR`, `isSemver`, and a field read as the result. A match condition's sentence starts *the policy applies only when*.
- [ ] A table test gives no sentence for each case the plan names: a `!` of a shape without a negative form (`!(a < b)`), a call not in the table, `true`, an unknown macro, `&&` and `||` mixed at one level, more than four clauses, more than 200 characters, and text that does not parse.
- [ ] A value is quoted from the source by the parser's offsets, in a code span, on one line: line breaks and indentation outside string literals become one space, and `'a  b'` keeps its two spaces. A value holding a backtick gets a longer delimiter.
- [ ] `FuzzSentence` (its seeds run in `go test`): never panics, and every value a sentence quotes is a substring of the expression with its whitespace outside strings made one space.
- [ ] In the hover, **Checks:** shows the sentence for a CRD `rule`, a policy validation's `expression`, a match condition, and a Kyverno validation; it is left out when the file's check has an error diagnostic starting inside the expression (a test with a misspelled field) and when there is no sentence. **Returns:** shows the plan's fixed sentence for a `messageExpression`, a variable, an audit annotation's `valueExpression` and a mutation (`applyConfiguration` and `jsonPatch`). A table test per field.
- [ ] `docs/engine.md` lists the shapes and when no sentence is shown; `CHANGELOG.md` has the entry.
- [ ] `go test -bench Sentence ./internal/meaning/` over the rules of `BenchmarkHover`'s CRD: under 50 µs a rule.

## Out of scope

Naming values in words ("the port" for `p.port`), the rule's `message`, sentences for shapes outside the table (a later issue may add rows, each with its tests).

## Notes

- Macros expand into comprehensions when parsed; parse with the macro calls kept (`parser.PopulateMacroCalls`) to see `all`, `exists` and the others as written, with the macros the Kubernetes environment declares.
- The words are the plan's table; a better wording for a row is welcome in review, with the table in the plan changed too.
