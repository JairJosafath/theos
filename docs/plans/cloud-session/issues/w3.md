## Context

Third step of `docs/plans/cel-lens-rule-view.md` (JairJosafath/cel-lens#2). The list has each rule's compile state and stays current. The request also asks, for rules that run on examples, whether those pass. The check of the examples already keeps what each rule did to each example, per file, open or not (`exampleFound[key].rules`), and package `inline` writes the line's words for it.

## Goal

Each rule in `cel-lens.ruleList` carries what its examples say, in the line's own words, and a `problem` flag the view filters and counts by.

## Acceptance criteria

- [ ] A rule of a CRD and a validation, match condition or audit annotation of a ValidatingAdmissionPolicy of `admissionregistration.k8s.io/v1` has `examples`: `{state, words}`, from the last check of the examples for the Kubernetes version in use, found by the same rule identity the line uses. `state` is `wrong` (a wrong verdict, at the rule or on an example it ran on), `error` (an example errors, and none is wrong), `pass`, or `notRun` (it ran on none); `words` is exactly the part the line above the rule shows, from `inline`, before the line shortens it. A table test in `inline` holds state and words for each kind of part.
- [ ] `examples` is `null` for a rule with no example, for a policy's variable, a MutatingAdmissionPolicy, a Kyverno policy, a ValidatingAdmissionPolicy of another version, while `exampleResults` is off, and while no check of the examples has run for the version in use. A rule never shows the results of another version.
- [ ] `problem` is true when `compile.state` is `error` or `warning`, or `examples.state` is `wrong` or `error`; `notRun` is not a problem. Tests cover each.
- [ ] When a check of the examples ends and what a listed rule did to its examples changed, the files whose entries changed get a new generation and the notification is sent, as for an edit. Turning `exampleResults` off clears every `examples` in one generation; turning it on fills them when its check ends.
- [ ] `docs/engine.md` describes `examples` and `problem`; `CHANGELOG.md` has the entry.
- [ ] The `ExampleRulesRunning` bench keeps its numbers: the list reads what the check of the examples kept, and runs no rule itself.

## Out of scope

New example results for a MutatingAdmissionPolicy or Kyverno: not in this plan. Folders: the next step.

## Notes

- The words are the UI: the view shows them as its description, so they must be the line's, never a second wording.
