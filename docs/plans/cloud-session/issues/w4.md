## Context

Fourth step of `docs/plans/cel-lens-rule-view.md` (JairJosafath/cel-lens#2). The request asks that the view work with several workspace folders. The engine reads the folders once, from `initialize`, and does not declare `workspace.workspaceFolders`, so VS Code never tells it of a folder added or removed: a folder added later is walked by nothing until the engine restarts, and one removed is still walked. That is already wrong for the CRD scan, the check of the examples and the `.cellens` search, and would leave the view without a folder's rules.

## Goal

The engine follows the workspace folders as they change, and every background run that walks them reads a folder added and forgets one removed, without a restart.

## Acceptance criteria

- [ ] `initialize` declares `workspace.workspaceFolders` with `supported: true` and `changeNotifications: true`, and the server handles `workspace/didChangeWorkspaceFolders`.
- [ ] A folder added is walked by the rule index, the check of the examples (while `exampleResults` is on), the `.cellens` search and the CRD scan (while `crd-typed-policies` is on), with the limits of the walk, the 20,000-file cap counted across all folders as today. Its rules, examples, `.cellens` types and CRDs count from then on, and the open documents are checked again when what they are typed from changed. A test per run.
- [ ] A folder removed is forgotten by each: its rules leave the list (`removed`), its examples, `.cellens` files and CRDs no longer count, and the diagnostics the server sent for its closed files are cleared. An open file in it stays, as an open file outside every folder does today.
- [ ] A folder inside another folder of the workspace is walked once, with the outer one (`outermost`), and each listed file names the deepest folder that holds it.
- [ ] While the walk of an added folder runs, `scan.state` is `scanning`.
- [ ] `docs/engine.md` says the server follows the folders; `CHANGELOG.md` has the entry, under *Fixed* for the runs that ignored a folder added.

## Out of scope

Per-folder settings in the engine (one switch per window stays: cel-lens#18). The view.
