## Context

The owner asked that giving a value your own type become an experimental feature. That covers **Give it a type** and the `.cellens` file that holds the types. The plan is `docs/plans/cel-lens-own-types-experimental.md` in theos.

Today the feature is on for everyone. The engine's experimental features are listed in `pkg/feature`.

## Goal

`.cellens` types are an experimental feature, `cellens-types`, off by default. Off, the engine behaves as if no `.cellens` existed. Engine v0.32.0 is ready to release from the released v0.31.0.

## Acceptance criteria

- [ ] `pkg/feature` knows `cellens-types`, and it is off unless listed. One place answers whether `.cellens` is read, and every path below asks it; no path checks the feature twice. A test lists those paths.
- [ ] **Off:**
  - No `.cellens` is searched for or read.
  - The line above a rule shows no **Give it a type** or **Edit**.
  - A value a `.cellens` would type is `dyn`, and its hover says the `cellens-types` feature is off, as hover does for `crd-typed-policies`.
  - An open `.cellens` gets no diagnostics, hover or completion.
  - The example results run with those values as `dyn`.
  - The commands behind *Give it a type* answer that the feature is off.
  - A server test covers each item.
- [ ] **On,** everything behaves exactly as in v0.31.0. The existing tests run with the feature on and pass unchanged.
- [ ] **Notice:** off, when the workspace holds a `.cellens`, the engine sends one notification per session. It says the file is not read because `cellens-types` is off, and offers a button that adds the name to `cel-lens.experimental` at the scope that already sets it, as the unknown-name notification's Replace button does. A test covers the notice, and that it is sent only once.
- [ ] **Switching:** turning the feature on or off through `workspace/didChangeConfiguration` takes effect without a restart. Open documents are checked again, and the `.cellens` search runs when it turns on. A test covers both directions.
- [ ] `docs/engine.md` lists the feature and what off means. `CHANGELOG.md` has it under Changed, saying plainly that a workspace with a `.cellens` needs `cellens-types` from this version on.
- [ ] **Prepare v0.32.0** in the same pull request, with `make release RELEASE=0.32.0`. The changelog section reads as one release's notes, and the README pins `@v0.32.0`.
- [ ] `make check`, `vet-windows` and `test-windows` pass.
