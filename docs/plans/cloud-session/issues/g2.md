## Context

Second step of `docs/plans/cel-lens-everything-one-step-away.md` (JairJosafath/cel-lens#3). The request: "The status bar item's menu is the hub: the Kubernetes version, the colour style, the toggles, the logs, restarting the engine. Each entry shows its current value and has an icon only where it helps."

Today the menu (`src/actions_menu.ts`, `VersionStatus.showActions` in `src/version_status.ts`, **Show Actions**) is one flat quick pick: *Color style* (`CEL`), *Kubernetes version* (`1.36`), *Inline info: on*, *Example results: on*, *Restart Engine*, *Show Logs*; with the engine down, the last two come first. Step 1 added *Toggle Colors*, *Toggle Value Types* and the context key `cel-lens.cellensTypes`.

## Goal

The menu holds every setting and toggle of cel-lens and the engine's two actions, in the request's order, each with its current value in words.

## Acceptance criteria

- [ ] `actionItems` (no `vscode` import) returns, in this order: *Kubernetes version* (description: the version in use, or the engine's state as `versionDescription` says it), *Color style* (`CEL`, `Classic` or `Off`); a separator *In the editor*; *Colors*, *Inline info*, *Example results* and, only while `cellens-types` is on, *Value types*, each with `on` or `off` as its description; a separator *Engine*; *Show Logs* with `$(output)` and *Restart Engine* with `$(debug-restart)`. Each runs its command (*Pick Kubernetes Version*, *Choose Color Style*, *Toggle Colors*, *Toggle Inline Info*, *Toggle Example Results*, *Toggle Value Types*, *Show Logs*, *Restart Engine*). Unit tests for the order, the labels, the descriptions in each state and the commands.
- [ ] No entry but the two engine entries has an icon; no label holds a value (*Inline info*, not *Inline info: on*).
- [ ] With the engine failed or crashed, the *Engine* group and its separator come first, then the others in the same order. A test.
- [ ] The values are those in force for the active editor's file, its workspace folder's included (`readInlineInfo`, `readExampleResults`, the new readers for `valueTypes` and the colours); with no editor, the window's. A test with a folder that turns one off.
- [ ] Separators are `QuickPickItemKind.Separator` items that run nothing; picking an entry runs its command and closes the menu; dismissing it runs nothing. Tests against `test/vscode.ts`.
- [ ] The quick pick keeps its title *cel-lens* and gets the placeholder *Pick a setting, a toggle or an action*.
- [ ] `src/button_labels.ts` stays the one place for *Restart Engine* and *Show Logs*.
- [ ] `CHANGELOG.md` has the entry under *Unreleased*; the README is step 7's.

## Out of scope

The editor's submenu (step 3), the shortcut (step 4), the status bar item's text and its `accessibilityInformation` (step 6). Keeping the menu open after a toggle: rejected in the plan's decision 4.
