## Context

Engine v0.32.0 makes giving a value your own type (**Give it a type** and `.cellens`) the experimental feature `cellens-types`, off by default. The plan is `docs/plans/cel-lens-own-types-experimental.md` in theos. The owner asked for a GIF of it in the README.

## Goal

The extension carries engine v0.32.0. The README lists `cellens-types` as experimental and shows it with a GIF. v0.40.0 is ready to release.

## Acceptance criteria

- [ ] `core-version.json` pins v0.32.0 from its release's `checksums.txt`, whose Sigstore signature is first verified with the `SECURITY.md` command.
- [ ] `cel-lens.experimental` in `package.json` lists `cellens-types` with a one-line description. The setting's description and the README's settings table name it.
- [ ] **cel-lens: Give a Value a Type…** with the feature off says so, and offers a button that turns it on at the scope that sets `cel-lens.experimental`. The command stays in the palette.
- [ ] **The README:**
  - `cellens-types` moves into the *Experimental* table, with what it does and why it is experimental: the types are yours, and nothing checks them against a cluster;
  - *Giving a value a type* opens with one sentence on how to turn it on;
  - the line describing **Give it a type** under the top picture says it needs the feature;
  - nothing else in the README changes unless it is now wrong.
- [ ] **The GIF:** `images/cellens-types.gif`, at the top of *Giving a value a type*, in place of the comment for `give-type-schema.png`.
  - Taken by `npm run pictures` in a dark theme, with the same lossless encoder as the other GIFs.
  - It shows `params: dyn · Give it a type` above a rule of a ValidatingAdmissionPolicy, then **Write a schema in .cellens…** picked, `.cellens` opening beside the rule, the schema typed with completion, and the line following to `params: {maxReplicas} · Edit`.
  - Its alt text says that.
  - It is under 2 MB, and the README test that checks the pictures covers it.
- [ ] An end-to-end case on the pinned engine shows the feature off and on: no **Give it a type** part off; the part, and a value typed from `.cellens`, on.
- [ ] v0.40.0: `package.json` and a changelog `## [0.40.0]` that reads as one release's notes. It says plainly that a workspace with a `.cellens` now needs `cellens-types` in `cel-lens.experimental`. `make dist VERSION=v0.40.0` writes six `.vsix`.
- [ ] `make check` passes.

## Out of scope

The rule view (cel-lens#2), which moves to v0.41.0.
