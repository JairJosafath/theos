The issue as the Crew files it on a repository with no AGENTS.md
(model.OnboardingIssue(false)):

TITLE: Write AGENTS.md for this repository, and say what you found

The factory adopted this repository as it is: it scaffolded nothing here, so nothing tells an agent 
how the repository is built. Every agent reads `AGENTS.md` before it works. This repository has no 
`AGENTS.md`. Write it.

## Goal

`AGENTS.md` at the repository's root says, from what the repository holds and what you ran, never 
from a guess:

- how to build it, how to run its tests and how to run it, each with the command;
- where things are: the code, the tests, the CI workflows, the configuration;
- what its conventions are, where the code shows them (naming, layout, how errors and logs are 
written);
- what not to touch, and why, where the repository says so.

Change no other file. In the pull request's description, list what you found that a person should 
know: a test that fails on main, a check that needs a secret or a service, a command the README 
names that doesn't work, a dependency without a lockfile. Say "nothing found" when that is so.

## Acceptance criteria

- [ ] `AGENTS.md` gives the commands to build, to test and to run the repository, and each was run
- [ ] It says where the code, the tests and the CI workflows are
- [ ] The pull request changes no file but `AGENTS.md`
- [ ] The pull request's description lists what was found, or says nothing was
