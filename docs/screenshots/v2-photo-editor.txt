- **README:** it now says the release manifest declares only `WRITE_EXTERNAL_STORAGE` (`maxSdkVersion="28"`) and no `INTERNET`. The existing manifest test already guards this.
- **Shared exports:** I did not delete the file right after sharing, because the share sheet reads it after `share` returns and an early delete could break the receiving app. Instead `main()` clears the share cache at start (`ExportRepository.discardSharedFiles`), and each new share clears it before writing. Tests cover both, plus a delete failure being ignored.
- **Undo/redo in the draft:** the saved draft now holds the whole `EditHistory` (present, undo and redo stacks), and the draft format version went from 1 to 2. A draft that is missing a field is ignored. The editor loads its own draft when it opens, but only if it is for the same photo.
- **Editor restoration:** the home page opens the editor as a restorable route, and the editor has `restorationId`s for its tool and scroll panel. The dependencies reach the route through a small `AppDependenciesScope`. The route builder and its class need `@pragma('vm:entry-point')`; without it the engine errors on restore.
- **Restoration test:** `app_test.dart` uses `restartAndRestore` to check that the editor, the open tool and the history (undo still enabled) come back.

Some existing tests changed to use `history:` instead of `edit:` on `Draft`.
