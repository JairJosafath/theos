# Code of Conduct

C4 Factory follows the
[CNCF Code of Conduct](https://github.com/cncf/foundation/blob/main/code-of-conduct.md),
version 1.3. It applies to everyone in the project's spaces, people and
agents alike: issues, pull requests, comments, commit messages, and the Gitea
instances the factory runs.

## Reporting

The repository is private for now. Report to the owner, @JairJosafath (see
[MAINTAINERS.md](MAINTAINERS.md)), privately and not in an issue. You get an
answer within 3 business days. No one is penalised for reporting in good faith.

## Enforcement

The owner handles reports about people. The maintainer applies the Code of
Conduct to what agents write: it marks a comment that breaks it as outdated,
posts a better one, and fixes the rule or prompt that caused it
([GOVERNANCE.md](GOVERNANCE.md)).
