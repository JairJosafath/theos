# Code of Conduct

theos follows the
[CNCF Code of Conduct](https://github.com/cncf/foundation/blob/main/code-of-conduct.md),
version 1.3. It applies to everyone in the project's spaces, people and
agents alike: issues, pull requests, comments, commit messages, and the Gitea
instances the factory runs.

## Reporting

Report to the owner, @JairJosafath (see [MAINTAINERS.md](MAINTAINERS.md)),
privately and not in an issue: through the contact on their GitHub profile,
or, for a report that is also a security matter, GitHub's private
vulnerability reporting ([SECURITY.md](SECURITY.md)). You get an answer
within 3 business days. No one is penalised for reporting in good faith.

## Enforcement

The owner handles reports about people. What an agent writes is held to the
same Code of Conduct: whoever sees a comment of an agent's that breaks it
marks it as outdated and posts a better one, and the rule or prompt that
caused it is fixed through an issue ([GOVERNANCE.md](GOVERNANCE.md)).
